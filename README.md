## 🕹️ About

IGTAP: an Incremental Game That's Also a Platformer is a single-player 2D precision platformer with incremental, automation, and resource-management mechanics, developed by Pepper Tango Games and published by Gamersky Games. Complete short platforming courses to earn power, then spend it on upgrades that improve production and movement abilities. Recorded routes create an army of clones that repeats your optimized path, turning platforming skill into steadily increasing income. Exploration, hidden bonuses, alternate routes, and harder remixed courses add depth beyond the core progression loop.

IGTAP is for players who enjoy precision platformers, incremental progression, automation, exploration, and optimizing repeatable routes.

## ✨ Features

- 🕹️ **Precision Platforming** — Master short, demanding 2D courses built around movement, timing, and route optimization.
- ⚡ **Incremental Progression** — Earn power from completed courses and reinvest it into increasingly efficient production.
- 🏆 **Achievement Hunting** — Pursue a broad set of achievements across platforming, progression, and exploration.
- 🔎 **Exploration Bonuses** — Search the world for hidden bonuses and optional discoveries.
- 💠 **B-Side Challenges** — Take on harder remixed versions of the courses after completing the main game.
- 👥 **Clone Automation** — Record your best routes and build an army of clones that repeats them automatically.
- 🏁 **Route Optimization** — Refine movement and pathing to improve both immediate runs and long-term production.
- ⬆️ **Movement Upgrades** — Unlock abilities that open new courses, shortcuts, and faster ways through familiar areas.
